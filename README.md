# Aluminium carbides under pressure

Étude computationnelle des carbures d'aluminium (Al₄C₃ et phases apparentées) sous pression.

## Description

Ce projet explore la stabilité structurale, les transitions de phase et les propriétés
physiques des carbures d'aluminium en fonction de la pression, à l'aide de méthodes de
calcul (DFT, dynamique moléculaire, etc.).
